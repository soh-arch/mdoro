# 役の生の報告

**ここにあるのは、役が返した報告そのものである。**要約も編集もしていない
（転写は `extract-report.py` が行った。オーケストレーターは書き写していない）。

**なぜ生で残すか。** 2026-09-12、オーケストレーターが集計を2箇所で間違えた ——
バイト数を文字数と書き、`grep` の文字列一致を「到達」と数えた。
**検証役がそれを捕まえられたのは、生の報告が手元にあったからである。**
**集計だけを残すと、次に同じ検算ができない。**

**読みと集計は別の場所にある** —— `docs/reviewer-model-results.md`（事実）と
`docs/reviewer-model-evaluation.md`（読み）。**ここと突き合わせれば、集計を独立に検算できる。**
