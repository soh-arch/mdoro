# 0031. メニューバーの印はセッションを示す。接続状態は示さない

- **状態**: accepted
- **日付**: 2026-08-28

## 文脈

REQ-UIX-035（旧条文）は、未接続・再接続中にメニューバーのテンプレート画像を専用の形状へ
変えることを求めていた。色を使えない場所（REQ-COL-022）で接続状態を伝える手段として、
形状に載せる判断だった。実装は「接続中はアプリの印、それ以外は OS の時計記号」で満たしていた。

工程12 でメニューバーの印を3枚（待機・全塗り / 計測中・水位 / 一時停止・中空）に描き替えた際、
**新しい印が画面に出てこない**という報告があった。調べると、アプリは正しくビルドされ、
アセットも解決できていた。出ていなかったのは**未接続だったから**である。

診断ログに残っていた接続の推移。

```
08:36 conn up=no
08:40 conn up=yes
08:40 conn up=no
08:41 conn up=yes
（以降なし。12:11 と 12:12 の app.start 後は一度も繋がっていない）
```

**iPhone は背面に回ると WebSocket が切れる**（3.5 のプラットフォーム制約。
`docs/CONTEXT.md` §3）。iPhone アプリを前面で開いている間しか接続は生きない。

> **訂正（2026-08-29）**: 上の「WebSocket が切れる」は**現行の一次情報で確認できていない**（唯一の出典は 2011年・iOS 4・archive の TN2277 で、しかも「切れる**ことがある**」）。**依拠すべきは「suspend 中はアプリのコードが実行されない」であり、判断そのものは動かない**（[`docs/platform/0002`](../platform/0002-live-activity-background-start-and-suspend.md)、SPEC v2.21）。

参照先も誤っていた（この主張は 3.5 になく、§3 は空である）。**正しくは
`docs/PLATFORM.md`「Live Activity — 開始と更新の門」。**

つまり**通常運用における既定の状態は「未接続」**であり、旧条文のもとでは:

- 新しく描いた3枚の印は、ほとんどの時間表示されない
- **Mac 単独で使う利用者には、アプリの印が一度も出ない**（常に時計に✗の記号だけ）

`docs/CONTEXT.md` の工程設計は「**Mac 単独で実用になる**ものを先に作る」であり、
その利用者にアプリの顔が出ないのは筋が通らない。

## 判断

**メニューバーの印は、セッションの実行状態だけを示す。接続状態は載せない。**

| 場所 | 接続状態を示すか |
| :---- | :---- |
| メニューバーの印（常時見える） | **示さない** |
| メニューバーのドロップダウン | 読むだけの1行（`iPhone: Not connected`） |
| メインウィンドウ下部の帯 | 点と短いラベル（[0026](0026-design-system-completion.md) / REQ-UIX-046） |
| 設定 → Connection | ペアリングの状態と操作 |

REQ-UIX-004 の「両端末で常時視認」を**非対称に緩める。**
iPhone は常時、Mac は常時表示を求めない。

## 理由・設計意図

**Mac にとって未接続は異常ではない。**

状態の正本は Mac にある（[0001](0001-mac-as-single-source-of-truth.md)）。
iPhone が繋がっていなくても、Mac はタイマーを回し、ログを書き、通知を出す。
**失われる機能が何もない。** 一方 iPhone にとって未接続は「操作できない」を意味する
（REQ-COM-013）。同じ事実が、両端末で重さが違う。

旧条文は、この非対称を見ていなかった。**両端末に同じ強さで出した結果、
Mac 側では「常態を警告し続ける」表示になっていた。** これは REQ-UIX-046 が
「正常な状態を帯で示してはならない」と述べていることの、記号版の違反でもある。

**メニューバーで常時見えている1つの記号は、いちばん高価な表示面である。**
そこに載せるべきは、利用者が繰り返し確かめたいもの — 集中しているのか、休んでいるのか、
止まっているのか — であって、Mac の動作に影響しない事実ではない。

## 影響

- **仕様**: REQ-UIX-035 を全面的に書き換え、REQ-UIX-004 を非対称にした（v2.9）。
  要件数は変わらない
- **コード**: `MdoroCore/MenuBarMark.swift`（実行状態 → 印）、
  `ConnectionStatus.menuBarSymbolName` と `menuBarUsesAppMark` を削除、
  `PomodoroMac/PomodoroMac/Views/MenuBarViews.swift`（印を常時表示し、ドロップダウンに1行追加）
- **アセット**: `MenuBarIdle` / `MenuBarRunning` / `MenuBarPaused` の3つ。
  正本は `docs/images/icons/mdoro-menubar-{idle,running-60,paused}.svg`
- **読み上げ**: 印が形で示す実行状態を、メニューバーのアクセシビリティラベルにも載せた
  （見えている人だけが分かる状態を作らない）

## 検討したが採らなかった案

- **印に斜線を重ねて未接続を示す** — 絵が3枚から6枚に増える。
  そこまでの表示面を割く価値が、Mac 側の接続状態にはない
- **接続状態を色で示す** — REQ-COL-022 が禁じている。メニューバーの地は可変で、
  コントラストを保証できない
