# 0025. 標準のチェックボックス記法だけを読む

- **状態**: accepted
- **日付**: 2026-08-27

## 文脈

[0023](0023-markdown-first-not-obsidian-first.md) で「Obsidian 専用ではなく md 全般」と決めたとき、
**他ツール固有の記法をどこまで読むか**を OPEN-018 として残していた。
具体的には Logseq の `TODO` / `DOING` マーカーと `id::` プロパティである。

## 判断

**標準の Markdown チェックボックス記法（`- [ ]` / `- [x]`）だけを読む。**

- Logseq の `TODO` / `DOING` / `NOW` マーカーは**タスクとして認識しない**
- `id::` などツール固有のプロパティは `stableId` の入力に使わない
- Obsidian のブロック ID（`^abc123`）は**既に実装済みであり、維持する**（[0023](0023-markdown-first-not-obsidian-first.md)）
- **README に、読む記法をそのまま書く。** 「対応しています」と曖昧に書かない

## 理由・設計意図

**中途半端な対応は、対応しないことより悪い。**
`TODO` マーカーを読めるようにすると、次に来るのは「`DOING` にすると自動で開始してほしい」
「完了したら `DONE` に書き換えてほしい」である。後者は
**`Task.md` へ書き込まないという第一原則（[0002](0002-task-md-read-only.md)）と正面から衝突する。**
読めることが、書けるはずだという期待を作る。

**チェックボックス記法は、どのツールでも書ける。** Logseq でも Obsidian でも素のエディタでも、
`- [ ]` は同じ意味で通る。**最も狭い共通部分が、最も広く届く。**

**対象読者は、自分の md を自分で書く人である**（[0021](0021-published-as-oss-named-mdoro.md)）。
「この記法だけを読む」と書いてあれば、その形で書ける。**明示は制限ではなく、契約である。**

将来の再考は否定しない。要望が実際に来たときに、この記録を読んでから判断する。
