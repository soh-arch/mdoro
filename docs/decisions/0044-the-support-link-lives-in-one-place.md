# 0044. 支援リンクは Mac の設定と README にだけ置く

- **状態**: accepted
- **日付**: 2026-09-02（人間の裁定）／ 2026-09-18（記録）
- **反映**: コード（2026-09-18、`fix/the-support-link-lives-in-one-place`）。`README.md` / `docs/CONTEXT.md` も同じ枝で合わせた。**`docs/SPEC.md` は変更なし**（下の「影響」の理由による）

## 文脈

[0021](0021-published-as-oss-named-mdoro.md) は支援リンクについて
**「置き場所は Mac / iPhone の設定画面の About 節に1つだけ」**と決めた。

**「1つだけ」が3通りに読まれていた。**

| 読み手が見たもの | そこに書いてあること |
| :---- | :---- |
| iPhone 側のコード | 「exactly one … here」 |
| Mac 側のコード | Mac にも1つある（`SettingsView.swift`） |
| `README.md` | 「once, and nowhere else」 |

**どれも嘘ではない。** 0021 は「アプリごとに1つ」の意味で書いており、実装はそのとおりである。
**しかし README は「the app」と単数で書いており、リポジトリ全体で1箇所と読める。**
実体は Mac と iPhone で2箇所である（POL-126）。

**支援リンクの多寡は敏感に読まれる。** 公開する以上、数え方が読み手によって変わる状態で出せない。

## 判断

**支援リンクは Mac の設定画面と `README.md` にだけ置く。iPhone の設定画面からは消す。**

[0021](0021-published-as-oss-named-mdoro.md) の「Mac / iPhone の設定画面の About 節に1つだけ」の行は、
**この判断が置き換える。** 0021 のそれ以外の判断（公開方針・名称・ライセンス・配布形態）は有効なままである。

## 理由・設計意図

**数え方を1通りにするためである。** 「アプリごとに1つ」と「リポジトリ全体で1つ」は、
コードを読む人と README を読む人で答えが変わる。**置き場所を1箇所に減らせば、どちらの数え方でも1になる。**

**Mac を残して iPhone を落とすのは、支援リンクが誰に向いているかによる。** タイマーを動かしているのは
Mac であり（状態の正本は Mac）、設定を触るのも普段は Mac である。iPhone は表示と操作の端末で、
**設定画面を開く機会がそもそも少ない。**

[0021](0021-published-as-oss-named-mdoro.md) の「ささやかに留める」という意図は変えていない。
**むしろ強める方向である** —— 集中を守るためのアプリが2箇所で寄付を募る必要はない。
