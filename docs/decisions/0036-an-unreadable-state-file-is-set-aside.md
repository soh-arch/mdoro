# 0036. 読めない状態ファイルは、上書きせずに退避する

- **状態**: accepted
- **日付**: 2026-08-28
- **反映**: 未（仕様書は v2.15、実装は工程14c）

## 文脈

[0035](0035-a-failure-needs-somewhere-to-arrive.md) で復元の失敗を画面に出すようにしたところ、**その文が事実と逆である**ことが検証で判明した。

画面に出る文:

> The saved state could not be read. **Mdoro left the file alone**; move it aside to start from a clean state.

実際の動作: `AppModel.init` は末尾で無条件に `persist()` を呼ぶ。`load()` が `.corrupted` /
`.unsupportedSchemaVersion` を投げた直後、**同じファイルを初期状態で上書きする。**
利用者が帯を読んだ時点で、**退避すべきファイルはもう存在しない。**

実測（検証時の再現プローブ）:

```
caught: unsupportedSchemaVersion(found: 99, supported: 1)
original bytes: 19  →  after bytes: 1389
file still the user's? false
```

**上書きは以前からの挙動であり、[0035](0035-a-failure-needs-somewhere-to-arrive.md) が新しく作ったのは「誤った案内が届くこと」である。**
ただし `StateStore.swift` の契約コメントは以前から「**黙って初期状態へ戻さない。
上書きするとユーザーの実績が消える**」と書いており、**コードが自分の契約を破っていた。**

巻き添えで失われるものが2つある。

- **`pendingLogEntries`**（REQ-LOG-005:「キューを失うとそのセッションの記録は二度と書かれない」）
- **`unsupportedSchemaVersion` が防壁である意味。** 新しい版で書いた状態を古い版で開くと、
  警告を出したうえで壊す

## 判断

**読めない状態ファイルは上書きしない。退避して残し、退避先を画面に示す。**

| 段階 | 動作 |
| :---- | :---- |
| 復元に失敗 | **読めなかったファイルを別名で残す**（`state.json.unreadable-<日時>` 等） |
| その後 | 新しい状態で通常どおり続行する。**以降の保存は普通に動く** |
| 画面 | 退避したことと、**退避先の場所**を示す（[0035](0035-a-failure-needs-somewhere-to-arrive.md) の帯） |

**利用者に手作業を求めない。** 「move it aside」と案内して待つ間、アプリは保存できないか、
待たずに壊すかのどちらかになる。**どちらも選ばない。**

## 理由・設計意図

**利用者のファイルは、アプリの都合で消してよいものではない。**
[0002](0002-task-md-read-only.md) が `Task.md` について定めた原則は、置き場所が
Application Support であっても変わらない。**読めないことと、消してよいことは別である。**

**退避すれば、両方の要求が同時に満たせる。** データは残り、アプリは動き続ける。
「保存しないで待つ」を選ぶと、帯を見なかった利用者はその日のセッションを丸ごと失う。
**気づかなかったことへの罰にしない。**

**日時を付けるのは、2度目があるからである。** 固定名にすると、2回目の破損が1回目の退避を消す。

## 影響

| 対象 | 内容 |
| :---- | :---- |
| 仕様書 REQ-ERR-017 | **読めないファイルを退避し、退避先を示すことを追記**（v2.15）。要件数は **243 のまま** |
| `FileStateStore` | 復元に失敗したファイルを別名へ移す経路を持つ |
| `StateStoreError.displayMessage` | 「move it aside」を、**退避したことと場所の案内**へ書き換える |
| `AppModel.init` | 復元失敗の直後に初期状態で上書きしない |
| `StateStore.swift` の契約コメント | 実際の動作と一致させる |

**退避に失敗した場合は、[0035](0035-a-failure-needs-somewhere-to-arrive.md) に従って画面に示す。** 退避できないまま上書きしない。

## 出典と確度

- **事実**: 判断は 2026-08-28 のプロダクトオーナーの選択（提示した3案のうち「自動で退避して続行」を採用）。
- **事実**: 上書きの再現は、独立コンテキストの検証役が `FileStateStore` に対する一時プローブで実測した
  （19バイト → 1389バイト、スキーマ 99 が消失）。プローブは実行後に削除され、リポジトリは無変更。
- **事実**: `StateStore.swift` の契約コメントが以前から上書きを禁じていたことは、同ファイルの記述による。
