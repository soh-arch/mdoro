# 0006. 既定プリセットは「標準 25/5/15」の1つだけを同梱する

- **状態**: accepted
- **日付**: 2026-08-24

## 文脈

プリセット機能を追加する際、Claude（当時の PM）が既定プリセットとして
「標準 / ディープワーク / ショート」の3種を同梱する案を提示した。

## 判断

**既定として同梱するのは「標準 25/5/15」の1つだけとする。** 提案された3種は採用しない。
プリセットが1件のときは、切替 UI をそのまま出さず「追加」への導線にする。

## 理由・設計意図

作業スタイルは個人差が大きい。**こちらが用意した候補は、多くの場合そのままでは使われない。**
使われないまま初回起動時の UI を複雑にするだけになる。追加はユーザーに委ねるほうがよい。

これは「選択肢を用意しておくと親切だろう」という前提そのものへの否定である。
**選択肢はノイズにもなる。** 既定値・テンプレート・候補を増やすときは、
「これは本当に使われるか、それとも捨てられるか」を先に考える。親切心で増やさない。
