# 0022. アプリの文字列は英語だけにする

- **状態**: accepted
- **一部置換**: [0032](0032-code-comments-are-english.md)（コードコメント・commit メッセージの行）
- **日付**: 2026-08-27

## 文脈

工程9は当初「日本語と英語の2言語」と決めていた（`CONTEXT.md` §6、2026-08-26）。
OSS として公開すること（[0021](0021-published-as-oss-named-mdoro.md)）が決まり、
**日本語 UI を持たない**という判断に変わった。

## 判断

**アプリが生成するテキストは、すべて英語にする。日本語 UI は持たない。**

| 対象 | 言語 |
| :---- | :---- |
| 画面・メニュー・通知・エラー文言 | **英語** |
| 実績ログ（`PomodoroLog.md`）が含むアプリ生成部分 | **英語**（曜日・終了理由・周回・延長の表記） |
| 診断ログ | **英語**（公開の issue に貼られる前提。[0018](0018-diagnostic-log-policy.md)） |
| 外部ファイルから読み取った文字列（タスク名・見出し） | **そのまま**。翻訳も正規化もしない |
| 利用者が入力した文字列（プリセット名など） | **そのまま** |
| `docs/` | **日本語のまま**（内部の作業言語。利用者に見えない） |
| コードコメント・commit メッセージ | **英語**（[0032](0032-code-comments-are-english.md) がこの行を覆した。境界は「利用者に見えるか」ではなく「誰が読むか」） |

**String Catalog（`Localizable.xcstrings`）は残し、開発言語を英語にする。**
言語は1つだが、カタログは残す。

## 理由・設計意図

**2言語を維持する費用が、得られるものに見合わない。**
文字列を1つ足すたびに2回書き、レビューも2回になる。
公開後は他人が足す文字列も増えるが、**その日本語訳の質を保証する手立てがない。**
訳が古い UI は、訳が無い UI より悪い。

**対象読者が英語のドキュメントを日常的に読む層である**（[0021](0021-published-as-oss-named-mdoro.md)）。
md でタスクを管理し、Xcode でビルドし、issue を英語で立てる人にとって、
日本語 UI の有無は採否の分かれ目にならない。

**カタログを残すのは、コードに文字列リテラルを散らさないため。**
将来 誰かが言語を足すとき、Swift ファイルを触らずに済む。
工程6以降の文字列はすでにカタログ経由で書いてある（2026-08-27 承認）。
**言語を1つに絞ることと、文字列を1箇所に集めることは別の話である。**

**外部由来の文字列に触れないのは、`Task.md` を読み取り専用とする原則の延長である。**
利用者が日本語でタスクを書いていれば、UI にもログにも日本語のまま出る。それが正しい。

## 影響

| 対象 | 内容 |
| :---- | :---- |
| 仕様書 第8章 | **REQ-UIX-038 を新設**（UI 言語は英語。外部由来の文字列は加工しない） |
| 仕様書 第7章 | 7.2 の出力例、REQ-LOG-003 の見出し形式を英語表記へ。`## 2026-08-24 (Mon)` |
| コード | 日本語の文字列リテラル **約290箇所**（Mac 183 / iOS 69 / Widget 7 / Core 27。2026-08-27 実測） |
| 既定プリセット名 | 「標準」→ `Standard`。既存の永続化済み設定にある名前は変わらない（利用者が改名できる） |
| タスクの未分類節 | `TaskParser.uncategorizedSection`（「（未分類）」）→ 英語 |
| `CONTEXT.md` §6 | 工程9の記述を「2言語」から「英語のみ」へ |

**既存のログファイルは壊れない。** REQ-LOG-003 の見出し判定は日付だけを見る（[0014](0014-log-day-heading-matching.md)）ため、
`## 2026-08-24 (月)` の見出しが残っていても、同じ論理日の行はそこへ追記される。
**過去の行を英語へ書き換えることはしない**（既存行の改変禁止。第14章）。

## 出典と確度

- **事実**: 方針は 2026-08-27 のユーザー決定（「日本語対応は必要ない」「外部ファイルからのタスクインポートをのぞいて英語で統一」）。
- **事実**: 文字列リテラル数は `grep` による実測。コメント中の引用を含むため、実作業量はこれより少ない。
- **事実**: 見出し判定が日付のみに依存することは [0014](0014-log-day-heading-matching.md) と `LogFileEditor` の実装による。
